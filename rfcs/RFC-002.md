## 1. Clinical Context / Contexto Psicoterapéutico

**EN:** Vocal prosody —rhythm, intonation, timbre, speech rate— is a high-validity clinical emotional biomarker. Variations in F0, jitter, shimmer, and HNR correlate with anxiety, depression, acute stress, and other clinical phenomena.

**ES:** La prosodia vocal —ritmo, entonación, timbre, velocidad del habla— es un biomarcador emocional de alta validez clínica. Variaciones en F0, jitter, shimmer y HNR se correlacionan con ansiedad, depresión, estrés agudo y otros fenómenos clínicos.

**EN:** This module extracts acoustic features and correlates them with emotional indicators, presenting the therapist with an **assistive interpretation**, never a diagnosis.

**ES:** Este módulo extrae features acústicas y las correlaciona con indicadores emocionales, presentando al terapeuta una **asistencia interpretativa**, nunca un diagnóstico.

## 2. Features to Extract / Features a Extraer

| Feature | Description / Descripción | Clinical Indicator / Indicador Clínico |
|---------|---------------------------|----------------------------------------|
| F0 | Base pitch / Tono base | Reduced range → depression / Rango reducido → depresión; elevated → anxiety / elevado → ansiedad |
| F0 Variability | Pitch variation / Variación del tono | Low → emotional restriction / Baja → restricción; high → instability / alta → inestabilidad |
| Jitter | Frequency instability / Inestabilidad de frecuencia | High → vocal tension, anxiety / Alto → tensión vocal, ansiedad |
| Shimmer | Amplitude instability / Inestabilidad de amplitud | High → emotional instability / Alto → inestabilidad emocional |
| HNR | Voice clarity / Claridad de voz | Low → "dull" voice, depression / Bajo → voz "apagada", depresión |
| Spectral energy | Energy distribution / Distribución de energía | Resonance changes → alert/calm / Cambios en resonancia → alerta/calma |
| Speech rate | Words per minute / Palabras por minuto | Increased → mania/anxiety / Aumentada → manía/ansiedad; decreased → depression / disminuida → depresión |
| Pause duration | Silences between utterances / Silencios | Long → slow processing, sadness / Largas → procesamiento lento, tristeza |

## 3. Architecture / Arquitectura

```
[Encrypted WAV / WAV cifrado] → [Local decryption / Descifrado local] → [Feature extraction (DSP) / Extracción (DSP)]
        ↓
[Per-patient normalization / Normalización por paciente] → [Correlation with baseline / Correlación con baseline]
        ↓
[Therapist: features + suggested interpretation + disclaimer / Terapeuta: features + interpretación sugerida + disclaimer]
```

**EN:** Technical: DSP library (OpenSMILE, Praat via JNI, or native Kotlin), 100% local, local Llama 3.2 (1B/3B) with structured clinical prompt, structured JSON output.

**ES:** Técnico: Librería DSP (OpenSMILE, Praat via JNI, o Kotlin nativo), 100% local, Llama 3.2 local (1B/3B) con prompt clínico estructurado, salida JSON estructurada.

## 4. Acceptance Criteria / Criterios de Aceptación

- [ ] 8 features with ≥ 90% accuracy vs Praat / 8 features con precisión ≥ 90% vs Praat
- [ ] 10 min audio in < 30 sec on mid-range device / 10 min de audio en < 30 seg en dispositivo mid-range
- [ ] AI interpretation ALWAYS includes disclaimer / Interpretación de la IA incluye SIEMPRE disclaimer
- [ ] Therapist marks: Validated / Corrected / Discarded / Terapeuta marca: Validado / Corregido / Descartado
- [ ] Per-patient learning: adjusts individual baseline / Aprendizaje por paciente: ajusta baseline individual

---

## 5. Ethical Notes / Notas Éticas

> **EN:** Prosody is a biomarker, not an oracle. A patient may have elevated F0 because they walked up stairs. AI suggests; therapist decides. Never present interpretation without session context and clinical history.

> **ES:** La prosodia es un biomarcador, no un oráculo. Un paciente puede tener F0 elevado por subir escaleras. La IA sugiere, el terapeuta decide. Nunca presentar interpretación sin contexto de sesión e historia clínica.
