## 🧠 Clinical Context / Contexto Psicoterapéutico

**[EN]** In a therapeutic session, the patient's audio contains highly sensitive biometric and emotional information. Any unauthorized transmission, leakage, or insecure storage constitutes a severe violation of professional secrecy and patient privacy.

**[ES]** En una sesión terapéutica, el audio del paciente contiene información biométrica y emocional de altísima sensibilidad. Cualquier filtración, transmisión no autorizada o almacenamiento inseguro constituye una violación grave del secreto profesional.

> **This module is the trust foundation. If it fails, the project loses clinical legitimacy.**  
> **Este módulo es la base de confianza. Si falla, el proyecto pierde legitimidad clínica.**

## 📋 Clinical Requirements (Mandatory) / Requisitos Clínicos (Obligatorios)

| # | Requirement / Requisito | Status |
|---|------------------------|--------|
| 1 | **Explicit consent / Consentimiento explícito** — Recording only starts after patient gives informed consent, registered in the system. / La grabación solo inicia después de que el paciente dé consentimiento informado, registrado en el sistema. | ⬜ |
| 2 | **100% local** — Audio NEVER transmits to external servers. Network verification disabled during recording. / El audio NUNCA se transmite a servidores externos. Verificación de red desactivada. | ⬜ |
| 3 | **Encryption at rest / Cifrado en reposo** — AES-256-GCM. Key derived from therapist PIN/biometrics. / AES-256-GCM. Clave derivada del PIN/biometría del terapeuta. | ⬜ |
| 4 | **Therapist control / Control del terapeuta** — Pause, resume, or stop at any time. / Pausar, reanudar o detener en cualquier momento. | ⬜ |
| 5 | **Visible indicator / Indicador visible** — Clear visual indicator visible to both therapist and patient during recording. / Indicador visual claro visible para terapeuta y paciente durante la grabación. | ⬜ |
| 6 | **Controlled export / Exportación controlada** — Only via biometric or PIN. No social sharing, email, or cloud. / Solo vía biométrica o PIN. No redes sociales, email, ni cloud. | ⬜ |
| 7 | **Configurable retention / Retención configurable** — Therapist defines retention. Secure deletion (overwrite) after period. / El terapeuta define retención. Borrado seguro (sobrescritura) tras el periodo. | ⬜ |

## ⚙️ Technical Parameters / Parámetros Técnicos

| Parameter / Parámetro | Value / Valor | Clinical Justification / Justificación |
|-----------------------|---------------|----------------------------------------|
| Sampling rate / Frecuencia de muestreo | ≥ 16 kHz | Prosody analysis (F0, jitter, shimmer) / Análisis de prosodia |
| Bit resolution / Resolución | 16-bit PCM | Quality/size balance / Balance calidad/tamaño |
| Format / Formato | Uncompressed WAV | Preserves original quality / Preserva calidad original |
| Channels / Canales | Mono | Sufficient for voice / Suficiente para voz |
| Encryption / Cifrado | AES-256-GCM | Industry standard / Estándar industria |
| Key derivation / Derivación | Argon2id + biometric/PIN | Brute-force resistant / Resistente a fuerza bruta |

## 🔄 User Flow / Flujo de Usuario

```
[Patient enters session / Paciente entra a consulta]
        ↓
[Therapist opens session / Terapeuta abre sesión]
        ↓
[System requests consent / Sistema solicita consentimiento]
        ↓
[Patient accepts (logged) / Paciente acepta (registrado)]
        ↓
[Indicator activates (visible to both) / Indicador se activa (visible para ambos)]
        ↓
[Session proceeds / Sesión transcurre]
        ↓
[Therapist stops recording / Terapeuta detiene grabación]
        ↓
[Audio encrypted → stored / Audio cifrado → almacenado]
        ↓
[Therapist reviews, annotates, or discards / Terapeuta revisa, anota, o descarta]
```

## ✅ Acceptance Criteria / Criterios de Aceptación

### Functional / Funcionales
- [ ] Native Kotlin (Android) / Kotlin nativo (Android)
- [ ] Consent UI with audited logging / UI de consentimiento con registro auditado
- [ ] Recording: 16kHz/16bit/Mono / Grabación: 16kHz/16bit/Mono
- [ ] Persistent visual indicator / Indicador visual persistente
- [ ] Encrypted storage / Almacenamiento cifrado
- [ ] Export after biometric auth / Exportación tras auth biométrica

### Tests / Tests
- [ ] **Network isolation / Aislamiento de red:** No HTTP/HTTPS during recording / Sin HTTP/HTTPS durante grabación
- [ ] **Encryption / Cifrado:** Unreadable without derived key / Ilegible sin clave derivada
- [ ] **Integrity / Integridad:** Modified byte detected as corrupt / Byte modificado detectado como corrupto
- [ ] **Secure deletion / Borrado seguro:** Forensic recovery impossible / Recuperación forense imposible

## 🛡️ Ethical Notes / Notas Éticas

> **[ES]** Este módulo es la **condición de existencia** del proyecto. Un psicólogo no puede usar una herramienta que no garantice, de forma demostrable, que la voz de su paciente nunca saldrá del dispositivo. La comunidad open source debe auditar este módulo y confirmar que cumple lo prometido.
